FCS call reports

Call report data for download

Links to call report data for each quarter dating back to March 2000 are provided below. Links to call report data from 1984 to 1999 are available on the Archives page of the FCA website.

Call report data are provided in comma-delimited text files. The call report data for a specific quarter may be downloaded to your system by executing one of the self-extracting files below.

Between 36 and 69 files will be created — of which half are data files and half are layout files:

  • The files beginning with “D_” provide a file layout and a description of the institution and each call report schedule.
  • The file labeled “INST0600.TXT” shows the system, district, association, reporting month and year, the UNINUM (i.e., each institution’s unique identifier), and the short name and mailing address for each FCS institution.
  • The last files contain the comma-delimited text data for each call report schedule for each FCS institution.
